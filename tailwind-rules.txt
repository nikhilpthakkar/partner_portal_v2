TAILWIND CSS v4 — @theme AUTO-GENERATED UTILITY RULES

RULE 1 — COLORS
@theme tokens:
--color-*

Auto utilities:
text-*            → color
bg-*              → background-color
border-*          → border-color
outline-*         → outline-color
ring-*            → --tw-ring-color
divide-*          → divide-color
fill-*            → fill
stroke-*          → stroke
accent-*          → accent-color
caret-*           → caret-color
decoration-*      → text-decoration-color

--------------------------------------------
